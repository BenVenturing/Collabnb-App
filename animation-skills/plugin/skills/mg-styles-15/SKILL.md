# mg-styles-15

Each style has a complete prompt in `prompts/` (one file per style). Read the prompt for the chosen style and follow it to build a 10-second motion film in code. `rubric.md` scores the result; `template.md` is the prompt skeleton. List `prompts/` to see the available styles and ask the user to pick one if they haven't.
