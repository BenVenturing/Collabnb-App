# Run Demos

From the project root:

```bash
cd "/Users/macbookair/Documents/Vibing/Collabnb App 2.0 (May 9th)"
```

## Mobile only (Expo)

```bash
npm run mobile
```

Shortcuts:

```bash
npm run mobile:ios
npm run mobile:android
npm run mobile:web
```

## Web only

```bash
npm run web
```

## Mobile + Web together

```bash
npm run dev
```

This starts both dev servers in one terminal session.
